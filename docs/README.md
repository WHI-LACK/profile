  作者书牌依次排开。

两张都是 2026-10-12 在内置浏览器里跑真实渲染截的图，窗口较窄（你全屏打开时书板会更大、
构图更舒展）。

## 二维码

- **`qr-live-site.png`**（760×760，ECC-H）
- **`qr-live-site.svg`**（矢量版，放大印刷不会糊）

两者都指向 https://whi-lack.github.io/profile/ 。是"深色码点 + 白色背景"的常规配色——
二维码请**不要把颜色反过来**（白码点黑底），相当一部分扫码器读不了反色码。
要贴到海报上的话用 SVG 那版；只发消息用 PNG 就够了。
